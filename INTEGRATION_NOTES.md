# Интеграция доработок UI и навигации

## Изменённые файлы

- **src/App.js** – добавлены состояния `selectedCity` и `chebDistricts`, реализован переход между городами в функции `handleCityNavigation`, удалена старая кнопка «Предложить правку» и добавлена новая треугольная кнопка с иконкой ✎; добавлена логика получения фотографий через `getFeaturePhotos`; панель описания теперь умеет отображать фотографии; добавлен блок навигации по городам; слои карты отображаются в зависимости от выбранного города.
- **src/App.css** – увеличена ширина красного треугольника «О карте»; добавлены стили для новой белой треугольной кнопки редактирования и иконки карандаша; добавлены стили для навигационных кнопок и их контейнера; добавлены стили для галереи фотографий в панели описания.
- **public/data/points.geojson** – для объекта «Лебедь, рак и щука» добавлено поле `photo` со значением `/images/features/lebed_rak_i_shchuka.png`.
- **public/data/cheboksary.geojson** – создан новый файл с пустым `FeatureCollection` для данных Чебоксар.
- **public/images/features/.gitkeep** – создана директория для хранения изображений объектов.

## Новые возможности

- **Треугольная кнопка «Предложить правку»** располагается слева в шапке, выполнена в виде белого треугольника (зеркальная копия кнопки «О карте») и содержит иконку ✎. При клике открывает прежнюю панель отправки заявки.
- **Красный треугольник «О карте»** расширен: его нижнее основание увеличено примерно на 60 px.
- **Навигация по городам**: в правом нижнем углу карты появляется панель с двумя кнопками — «Пермь» и «Чебоксары». При нажатии карта плавно перемещается в центр соответствующего города и отображаются слои только выбранного города.
- **Поддержка фотографий в панели описания**: если в свойствах объекта присутствуют `photo` (строка) или `photos` (массив), изображения автоматически подставляются в информационную панель. Относительные пути автоматически дополняются значением `PUBLIC_URL` для корректной работы на GitHub Pages. Если фотографий нет, блок с фото не отображается.
- **Пример**: у объекта «Лебедь, рак и щука» в файле `points.geojson` добавлено поле `photo`, поэтому при клике на этот объект будет показана фотография (изображение нужно разместить в `public/images/features/lebed_rak_i_shchuka.png`).

## Как проверить фронтенд

1. Перейдите в корень проекта и установите зависимости:

   ```sh
   npm install
   ```

2. Соберите приложение и запустите сервер разработки:

   ```sh
   npm run build
   npm start
   ```

3. Проверьте в браузере:
   - карта загружается и показывает слои Перми;
   - красная кнопка «О карте» стала шире;
   - слева в шапке появилась белая треугольная кнопка с иконкой ✎, которая открывает форму отправки;
   - панель навигации отображается в правом нижнем углу карты, при нажатии на «Чебоксары» карта перемещается в центр Чебоксар и скрываются слои Перми (отображаются данные из `cheboksary.geojson`);
   - при клике на объект «Лебедь, рак и щука» в панели описания появляется фотография (если изображение находится в указанной папке).

## Как проверить Worker

В данном пакете Worker не изменялся, но для его проверки:

```sh
cd worker
npm install
npm run dev
curl http://localhost:8787/health
```

## Как добавить секрет для GitHub‑бота

```sh
cd worker
npx wrangler secret put GITHUB_TOKEN
```

В интерактивный ввод вставьте ваш GitHub token с правами на создание Pull Request.

## Как задеплоить Worker

```sh
cd worker
npm run deploy
```

## Как задать URL backend во фронтенде

Создайте в корне проекта файл `.env.local` (он не включён в репозиторий) со строкой:

```env
REACT_APP_SUBMISSIONS_API_URL=https://vernacular-map-submissions.<ваш-subdomain>.workers.dev
```

После изменения переменных нужно перезапустить сборку фронтенда.

## Как задеплоить GitHub Pages

```sh
npm run build
npx gh-pages -d build
```

Убедитесь, что переменная `REACT_APP_SUBMISSIONS_API_URL` указывает на задеплоенный Worker.

## Добавление фотографий в объекты

1. Поместите изображение в папку `public/images/features/` (например, `public/images/features/lebed_rak_i_shchuka.png`).
2. В соответствующем объекте GeoJSON добавьте поле `photo`:

   ```json
   "photo": "/images/features/lebed_rak_i_shchuka.png"
   ```

   либо массив `photos`:

   ```json
   "photos": [
     {
       "src": "/images/features/example.jpg",
       "alt": "Описание фото",
       "caption": "Подпись"
     }
   ]
   ```

3. Соберите и запустите фронтенд. При клике на объект в панели описания будет показано изображение. Если для объекта нет фото, блок не отображается.

## Сопоставление названий с PDF

Автоматическое извлечение данных из PDF «Пояснение и этимология некоторых названий на карте» в этой версии не реализовано, поскольку файл недоступен для парсинга. Для обновления описаний объектов рекомендуем вручную сопоставить названия из PDF с полями `name` в GeoJSON и добавить или обновить поле `explainer` в соответствующих объектах `points.geojson`, `lines.geojson` и `districts.geojson`. Можно составить таблицу соответствий и применить её с помощью скрипта.
